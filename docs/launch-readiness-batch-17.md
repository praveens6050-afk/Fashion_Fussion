# Launch readiness batch 17 — Help Center & FAQ

## Goal
Create a customer-facing self-service Help Center for common Fashion_Fussion questions without changing commerce behavior.

## Changes
- Added `faq.html` with accessible expandable answers for delivery, COD, order tracking, cancellations, returns, refunds, business buying, GST, stock visibility, account usage and payment safety.
- Grounded answers in the currently implemented storefront and published policy behavior.
- Added `Help Center & FAQ` to the homepage Help links.
- Added a Help Center entry to `contact.html`.
- Added the FAQ page to `sitemap.xml`.
- Added the production canonical Link header for `/faq.html` in `vercel.json`.

## Guardrails
- No fixed delivery-day guarantee added.
- No fixed return window invented.
- No automatic bulk-discount promise added.
- No stock reservation or authoritative stock claim added.
- No universal GST-invoice guarantee added.
- No instant-refund timing promise added.
- Pricing, checkout, payments, orders, inventory, promotions, quote logic, APIs and database behavior are unchanged.
