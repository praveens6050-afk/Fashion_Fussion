# Launch Readiness Batch 11

This batch adds a public Returns, Cancellations & Refunds page based on the store's existing cancellation, return/exchange and refund behavior.

The page intentionally avoids inventing a fixed return-day window, exchange-stock promises or instant refund timing. It explains that cancellation is state-dependent, delivered-order return/exchange requests require review, prepaid cancellation excludes the recorded delivery component, and some COD or discounted-order return refunds require support-assisted handling.

The policy is linked from the homepage Help footer and Contact & Support page, published in the sitemap and given a canonical production URL.

No pricing, checkout, payment, order, inventory, promotion, API or database behavior is changed.
