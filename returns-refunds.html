Customer policy

Returns, cancellations & refunds

This page explains the current Fashion_Fussion order workflow. Order-specific actions and statuses shown in My Orders or Order Details reflect the actual state of your order.

Order-specific eligibility matters. A cancellation, return, exchange or refund is not confirmed until the store accepts or processes that action for the relevant order.

Cancelling an order

Customer cancellation is available only while fulfilment remains at the ordered or packed stage and the order is in an eligible payment state. Once fulfilment progresses beyond those stages, the normal customer cancellation action is no longer available.

  • For an eligible Cash on Delivery order cancelled before payment is collected, no payment refund is required.
  • For an eligible prepaid order, the refundable amount is calculated from the recorded order values and any due refund is sent to the original payment method.
  • The recorded delivery component is not included in a prepaid cancellation refund.

Returns and exchanges after delivery

Once an order is marked delivered, Order Details can offer item-level actions to request a size exchange, return for refund, or report an issue. A request includes the item, quantity and reason, and is reviewed before resolution.

  • Exchange availability is confirmed after review; requesting a size does not reserve or guarantee stock.
  • A return request is not the same as an approved refund. Refund processing begins only after the return reaches an eligible approved state.
  • Where the storefront presents an action, submit the request from Order Details so it stays tied to the correct order and item.

How return refunds are handled

For an approved, eligible prepaid return that does not require special discount allocation, the automated refund path uses the returned quantity's recorded item value, including the applicable GST recorded for that item, and sends the refund to the original payment method.

  • Orders involving coupon or gift-card discounts may require support-assisted allocation before a return refund is processed.
  • Cash on Delivery return refunds require a verified payout destination and are handled with support/admin review rather than the automated prepaid-refund path.
  • Payment-processor status may be pending before a refund is shown as processed. Fashion_Fussion records the available refund status and reference for tracking.

Delivery charges and refund timing

The current store checkout applies a ₹49 delivery charge below a ₹299 product subtotal. For customer-initiated prepaid cancellation, the recorded delivery component is non-refundable. Refund completion timing depends on the payment processor and receiving bank or payment method, so Fashion_Fussion does not promise an instant credit after initiation.

No stock or processor-timing promise: exchange stock is confirmed only after review, and a refund marked initiated or pending has not necessarily reached the receiving account yet.

Get help or track an order

Use your account for order-specific cancellation, return and refund status. If an action needs manual review—such as a discounted-order allocation or COD return payout—contact Fashion_Fussion support with the relevant order details.
