Overview

Fashion_Fussion ("we", "us", "our") operates this website to sell home, kitchen, beauty, and lifestyle products. This Security Policy explains how we handle the security of your data when you browse, create an account, place an order, or contact us.

Current security model: Browsing the catalog is public, while checkout requires an authenticated customer account. Payment processing uses Razorpay-hosted checkout. The site does not receive or store full card numbers, UPI PINs, CVV values, or net-banking passwords. Orders are created server-side and payment responses are verified before an order is treated as paid.

Data we collect

When you use this site or place an order, we may collect:

InformationWhy we collect it
Name, phone number, emailTo create your account, communicate with you, and process your order
Order contentsTo calculate, create, verify, and fulfil orders
Messages you send usTo handle support, returns, and enquiries

The current checkout does not collect a delivery address. If delivery-address collection is added later, this policy will be updated before or when that feature is introduced.

We do not ask for or store card numbers, UPI PINs, CVV, or net-banking passwords on this site.

Payment security

  • Razorpay handles the hosted payment UI and payment credentials.
  • Our backend creates Razorpay orders using server-side credentials that are not exposed to the browser.
  • Payment responses are cryptographically verified on the server before an order is marked paid.
  • The backend checks the payment status, order ownership, and paid amount against the stored order amount.

Account & browsing security

  • The storefront is served over HTTPS on the deployed GitHub Pages site.
  • Customers must authenticate before checkout; the backend also verifies the Supabase access token.
  • Cart information used by the storefront is held in the browser. Server-side order records are created during checkout.
  • Customers should keep their device and browser updated and avoid sharing passwords or using untrusted devices for account access.

Third parties

We use service providers needed to operate the store, including:

  • Supabase for authentication and database services
  • Razorpay for payment processing
  • GitHub Pages for public website hosting
  • Vercel for backend API hosting

Only information necessary for the relevant service should be transmitted to these providers. We do not intentionally sell customer information to advertisers or data brokers.

Data retention

We retain account and order records for as long as reasonably needed to operate the store, handle support and disputes, and meet applicable accounting or legal obligations. Deletion requests may be subject to records that we are required to retain.
